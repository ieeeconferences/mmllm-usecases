# Multimodal LLMs for Generating UML Use Case Models

This repository contains the companion dataset and prompt templates for the paper evaluating the capabilities of **Multimodal Large Language Models (MM-LLMs)** in generating UML Use Case models directly from hand-drawn Use Case diagrams.

---

## 📁 Repository Structure

* **`GXX.jpg`**: Hand-drawn UML Use Case diagrams created by different groups, where `XX` represents the group identifier (e.g., `G02.jpg`, `G03.jpg`, `G12.jpg`).
* **[`prompt_use_case_models_from_images.txt`](prompt_use_case_models_from_images.txt)**: The exact prompt provided to the analyzed Multimodal LLMs during the experiments to extract actors, use cases, and relationships from the image artifacts.
